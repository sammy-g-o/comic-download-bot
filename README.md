Comic Search Script
This Python script uses Selenium to automate a search for a specific comic on the website getcomics.org.
Prerequisites
Python installed on your system.
The selenium library:
pip install selenium


The Chromedriver executable in the same directory as the script. You can download it from the official Chromedriver website.
How to Use
Make sure all prerequisites are installed.
Run the script from your terminal:
python "comic download.txt"


The script will prompt you to enter the name of the comic you want to search for.
A new Chrome browser window will open and automatically perform the search. The script will quit after 10 seconds.
Note: This script is designed for the getcomics.org website. Changes to the site's layout or search functionality may require updates to the script.
